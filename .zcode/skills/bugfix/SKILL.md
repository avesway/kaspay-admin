# Bugfix (kaspay-admin)

## Шаги

1. **Локализовать**: по стеку/описанию найти модуль в `src/modules/<feature>`. Помнить поток: component → process → api → store.
2. **Определить слой бага**:
   - Неверный запрос/URL/параметры → `<name>.api.js` или сборка `params` в process.
   - Неверное состояние (loading/error не сбрасываются, stale-данные) → `<name>.store.js` / process (проверить `.finally`, merge `loading`/`error` через спред).
   - Ошибка рендера/отображения → `components/`.
   - 401/редирект на логин → `src/config/axios.js` (токен `X-BID-Token`, `localStorage[ENV.AUTH_TOKENS]`).
3. **Минимальный фикс**: менять только затронутый слой; не рефакторить попутно.
4. **Проверить побочные эффекты**: кто ещё использует этот стор/process/компонент.
5. **Верификация**: `npx eslint` на изменённых файлах; воспроизвести сценарий через `npm run dev` (mode=test).
6. **Сообщить честно**: что проверено, что нет.

## Частые места ошибок (по коду проекта)
- Пагинация: `page/size` в сторе, сервер ждёт конкретные имена — сверять с реальным API-модулем.
- Числа из форм приходят строкой — проект решает через `z.preprocess(Number, ...)`.
- Деньги в копейках — конвертация только через `src/helpers/priceHelpers.js`.
